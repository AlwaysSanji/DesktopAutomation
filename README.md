# DesktopAutomation

Instead of manually organizing files on my Desktop, I created a script that automatically categorizes files based on their extensions.

📁 Videos → Videos
🖼️ Images → Photos
🎵 Audio → Audio
📄 Documents & code → Files
🔗 Shortcuts → Apps
📦 Other files → Others

Next step: adding more file types, duplicate-file handling, logging, and eventually a simple GUI.
